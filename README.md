# 📚 Research Surveys & Explorations

Welcome to STAR group's central repository for literature reviews and exploratory research surveys. 

这里是我们组用于沉淀和共享**新研究方向调研、文献综述以及前沿追踪**的公共仓库。我们鼓励大家将日常的阅读笔记、体系化的调研文档汇总于此，促进组内的知识共享与灵感碰撞。

## 📂 目录结构 (Directory Structure)

为了保持仓库的整洁，请按**研究方向/主题**来划分顶层文件夹，在每个主题文件夹内按**具体子方向或作者**进一步组织文档。

示例结构：
```text
.
├── Self-Evolving-AI/             # 主题：自我进化系统
│   ├── Wanli-Survey-on-Self-Evoling-LLMs.md
│   └── reference_papers/         # 相关核心论文 PDF 或链接
├── Auto-Research-Agents/         # 主题：自动化研究 Agent
│   └── Agent-based-Auto-Research-Overview.md
├── RL-for-System1/               # 主题：强化学习与 System 1 召回
│   └── 2026-05-Survey-on-RL-Recall.md
└── template.md                   # 调研文档的标准模板
```

## ✍️ 贡献指南 (How to Contribute)
新建文档：如果你探索了一个全新的方向，请在根目录下新建一个主题文件夹（如 Multimodal-Agents/）；如果是在已有大方向下的细分调研，请直接放入对应文件夹。

命名规范：文档建议使用 Markdown/PDF 格式。命名请尽量包含日期或作者+核心主题，例如 2026-05-Wanli-Self-Evolving-Agents.md。

内容建议：

调研背景与动机 (Motivation)

核心脉络与代表性工作 (Key Milestones & Papers)

当前痛点与挑战 (Current Challenges)

未来可做的切入点 (Potential Ideas/Directions)

提交方式：直接在 main 分支 Commit 即可，或者通过 Pull Request 提交（附带简短的更新说明）。
